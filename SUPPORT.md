# Support

## How to Get Help

Thank you for using GitHub PI Scanner! We're here to help you get the most out of the tool.

### Documentation

Before seeking help, please check our comprehensive documentation:

- [README](README.md) - Installation, usage, and basic configuration
- [CONTRIBUTING](CONTRIBUTING.md) - How to contribute to the project
- [Developer Guide](docs/DEVELOPER_GUIDE.md) - Development setup and architecture
- [Design Overview](docs/DESIGN_OVERVIEW.md) - Detailed technical design
- [Security Design](docs/SECURITY_DESIGN.md) - Security architecture and considerations

### Getting Help

#### GitHub Discussions (Recommended)

For questions, ideas, and general discussion:
- Visit our [GitHub Discussions](https://github.com/MacAttak/pi-scanner/discussions)
- Search existing discussions before creating a new one
- Choose the appropriate category for your topic

#### Issue Tracker

For bug reports and feature requests:
- Check [existing issues](https://github.com/MacAttak/pi-scanner/issues) first
- Use our issue templates for consistent reporting
- Provide as much detail as possible

#### Security Issues

For security vulnerabilities:
- **DO NOT** open a public issue
- Email macmilky1@gmail.com directly
- See [SECURITY.md](SECURITY.md) for details

### Response Times

We aim to respond to:
- Security issues: Within 24 hours
- Bug reports: Within 3 business days
- Feature requests: Within 1 week
- General questions: As community availability permits

### Community Guidelines

When seeking support:
1. Be respectful and constructive
2. Provide context and examples
3. Search existing resources first
4. Help others when you can

### Commercial Support

For enterprise support needs or custom development:
- Contact macmilky1@gmail.com for options

### Contributing Back

The best way to ensure the project's health is to contribute:
- Report bugs with reproducible examples
- Submit pull requests for fixes
- Improve documentation
- Help answer community questions

Thank you for being part of the GitHub PI Scanner community!
